# Visa Maya — Autonomous Spend Control

A deterministic, offline-first React product experience for multi-agent procurement and spend control.

## Run locally

```bash
npm install
npm run dev
```

Visa Maya includes three prompts, a controllable authentication pass/fail path, editable budget envelopes with hard-cap enforcement, a synchronized 17.5-second live agent run, purchases by category, and a final spend summary.

The Coffee Stand request is prefilled when the product opens. Use the minimal up/down arrows inside the request panel to rotate through Home Bakery and Mobile Pet Grooming. The text remains fully editable.

Use the small **Auth path** control in the lower-right corner to intentionally show either authentication outcome. A failed attempt always succeeds when **Try again** is selected.
